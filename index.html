Troubleshooting

Resolve common issues quickly using focused support guidance.

Embedded playback may be limited when the page is opened directly from a local file. Use the Open Video link below the tutorial to view the original YouTube page in a new tab.

Material link does not open as expected

Google Drive resources may depend on browser access rules. If a preview is unavailable, use the original Open PDF link and continue in the new tab.
